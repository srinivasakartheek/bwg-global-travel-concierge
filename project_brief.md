# My agent: Global Travel Concierge & Itinerary Planner
One-liner: A conversational agent that helps travelers plan optimized, day-by-day city itineraries and manage trip budgets with a curated catalog of destinations, attractions, and activities.

Tool coverage:
- Memory: User travel style (e.g. luxury vs. budget, fast-paced vs. relaxed), dietary restrictions, home airport, favorite past destinations, and budget preferences across sessions.
- Tools: Look up destination attractions, fetch current weather forecasts, calculate distances/sequencing for spot ordering, and calculate/break down trip expenses.
- Catalog/UI: Collection of recommended spots, daily timeline itineraries, and itemized budget estimates rendered as structured cards and tables (A2UI).
- Image gen: Visual postcards, destination mood boards, and landmark preview photos.
- Sandbox: Route time optimization and multi-currency / budget computation.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for route optimization & budget math, Google Maps / Places API integration, and Cloud Trace for monitoring tool calls.
